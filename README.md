# Mi-Afinador-de-shamisen
# 三味線チューナー

マイクで三味線の音程を測る、1枚のHTMLだけのチューナーです。スマホのブラウザで動きます。

- 調弦: 本調子 / 三下り / 三上り
- 一の糸の音（調子）を12音から選ぶと、二の糸・三の糸の狙いの音が決まります
- マイクで測る: 弾いた音と狙いの音との差をセント（±50）で表示。±5セント以内で「ちょうど」
- 基準音を聴く: 持続音または撥の音で各糸の音を鳴らし、耳で合わせられます
- 基準A4は430〜450Hzで変更できます

## 調弦の音程

| 調弦 | 一の糸 → 二の糸 | 二の糸 → 三の糸 | 一の糸が C のとき |
| --- | --- | --- | --- |
| 本調子 | 完全4度 | 完全5度 | C - F - C |
| 三下り | 完全4度 | 完全4度 | C - F - B♭ |
| 三上り | 完全4度 | 長6度 | C - F - D |

## 使い方

マイクはHTTPSのページでないと使えません。GitHub Pagesなどで公開したURLを開いてください。
`index.html` を端末にダウンロードして直接開く方法では、マイクが使えないことがあります。

## GitHub Pagesで公開する

1. このフォルダ（`index.html`）をリポジトリのルートに置いてpushします。
2. リポジトリの Settings → Pages で、Branch を `main`、フォルダを `/ (root)` にして保存します。
3. 表示されたURLをスマホで開き、マイクを許可します。

## 判定のしくみ

マイク入力にYIN法で基本周波数を求め、近い音名の狙いとのずれをセントで出します。
オクターブは区別しません。本調子は一の糸と三の糸が同じ音名なので、両方の行が光ります。
音が大きく外れているときは、糸の行をタップして狙いを固定してください。
